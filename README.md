# Crypto Credits App

Un'applicazione completa per generare crediti, convertirli in criptovalute o valute fiat, e prelevare fondi verso wallet come **Kraken**, **MetaMask** e **TrustWallet**.

---

## 🚀 Come Iniziare

### Prerequisiti
- Node.js (v16 o superiore)
- Docker
- PostgreSQL
- Account Kraken (per le API)
- MetaMask (per test con Ethereum)
